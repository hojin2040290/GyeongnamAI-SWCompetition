# 알바지킴이 (로컬 실행용)

청소년 중심 아르바이트 근로권익 점검 및 보호 AI 에이전트. 지금 버전은 **AI 모델을 연결하지 않은 상태**로,
기록, 계산, 법 기준값 대조, 자동 점검, 증거 보존, 상담 사전 자료가 실제로 동작한다.

## 실행
```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # 필요한 값만 채우기 (비워도 실행됨)
uvicorn app.main:app --reload
```
브라우저에서 http://localhost:8000 을 연다. (vLLM을 8000번에 띄울 예정이면 `--port 8080`처럼 다른 포트로 실행)

테스트: `pytest`

목표 성능 측정: `python -m evaluation.run` (위반 의심 누락 0건, 급여 계산 100% 일치 확인)

## 구조
```
app/
  main.py            FastAPI 진입점 (화면과 API를 함께 제공)
  routers/api.py     화면이 부르는 API
  agent/core.py      에이전트 판단 반복 (지금은 규칙 플래너, AI 연결 후 LLM 도구 호출로 교체)
  agent/tools.py     에이전트 도구 (사용자 번호는 코드가 고정해 다른 사용자 기록에 접근 불가)
  judge/engine.py    법 기준 대조와 검증 장치 (정상, 확인 필요, 위반 의심)
  calc/              시간, 나이, 근무 시간표, 실제 근무 기록, 임금과 퇴직 정산 계산
  law/fetch.py       법제처 API로 조문을 불러와 법 기준표(DB)에 저장
  law/lookup.py      판단 결과에 법 기준표 조문 원문 연결 (없으면 '법 기준표 미구축')
  llm/client.py      AI 모델 호출 자리 (LLM_ENABLED=false면 사용 안 함)
  guard.py           보복 금지 안내, 공개 게시물 검색, 화면 캡처 보존
  report.py          상담 사전 자료 문서 만들기
  scheduler.py       매일 정해진 시각에 월급날 점검, 퇴직 정산 점검, 신고한 사업장 게시물 검색
  storage.py         업로드 원본 저장 (sha256 함께 기록)
data/law_params.json 판단에 쓰는 법 기준값과 출처 (verified=false 항목은 원문 재확인)
web/templates, web/static   화면
tests/               계산, 판단, API 흐름 테스트
evaluation/          정답 사례 묶음(cases.json)과 목표 성능 측정
```

## AI 연결과 역할 분담
법 조항 해당 여부와 상황 판단은 AI가, 시간과 금액 계산은 코드가 한다.

| 기능 | AI 연결 전 (LLM_ENABLED=false) | AI 연결 후 |
|---|---|---|
| 계약서, 급여명세서 사진 읽기 | 원본만 저장, 사용자가 직접 입력 | 비전 모델이 읽어 칸을 채우고 사용자가 확인 후 저장 |
| 법 조항 판단 (계약서 점검, 퇴근 점검, 지원 전 확인) | 코드는 사실과 근거만 정리, 결과는 '확인 중'. 필요한 정보가 없으면 '확인 필요' | AI가 정상, 확인 필요, 위반 의심으로 판단하고 코드 계산과 어긋나면 검증 장치가 확인 필요로 되돌림 |
| 급여 비교, 퇴직 정산 | 금액 차이와 지급 기한만 계산해 알림, 체불 여부는 '확인 중' | AI 판단 연결 예정 |
| 보복성 게시물 | 주소, 시각, 화면 보존 후 판별 대기 | AI가 판별 |
| 보복 금지 안내 | 정해진 문구 (사용자가 고칠 수 있음) | 상황에 맞게 AI가 작성 |

연결 방법: `.env.example`을 `.env`로 복사하고 `LLM_ENABLED=true`, `LLM_BASE_URL`, `LLM_MODEL`(비전 모델이면 사진 읽기도 같은 모델)을 채운 뒤 서버를 다시 켠다.

## 외부 API (없으면 해당 기능만 건너뜀)
- `LAW_OC`: 법제처 국가법령정보 공동활용 (신청할 때 등록한 IP에서만 호출됨)
  - `python -m app.law.probe`: 신청한 API의 응답 구조 확인 (결과는 law_probe_result.txt)
  - `python -m app.law.fetch`: 법 기준표 만들기. 근로 관련 법령 7개의 현행 조문과 별표, 고용노동부 최저임금 고시의 시간급(law_params.json보다 우선), 점검 주제별 판례·법제처 해석례·고용노동부 해석·노동위원회 결정문
  - 매일 자동 점검 때 법령 현행 판이 바뀌었으면 바뀐 법령만 다시 받는다
- `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`: 공개 게시물 검색
- 게시물 화면 캡처: `pip install playwright && playwright install chromium`

## 화면
- 홈: 출퇴근 버튼, 일하는 곳 근무 기록, 퇴직 정산, 알림. 퇴근을 누르면 에이전트가 그날 기록을 바로 점검
- 급여: 달별 급여 계산과 받은 금액 비교, 저장한 금액 고치기와 지우기
- 계약서: 기본 정보, 계약서, 실제 근무 기록을 법 기준표와 대조
- 자료: 증거 자료, 상담 사전 자료 만들기와 다시 열기
- 보호: 신고 후 보복 대응, 게시물 검색어 등록, 게시물 보존
- 모든 화면에 뒤로 가기가 있고, 휴대폰과 브라우저 뒤로 버튼도 같게 동작
- 계약서 칸, 안내 문구, 위치 기록 동의, 마지막으로 보던 일하는 곳과 탭은 바로 저장돼 새로고침해도 그대로다.
- 사업장 정보는 홈의 정보 수정, 생년월일은 일하는 곳 선택 창의 내 정보 수정에서 언제든 고칠 수 있다. 출퇴근 시각은 증거라 고치거나 지울 수 없고, 잘못 누른 기록은 "실수로 누름" 표시(표시 시각과 이유가 남음)로 계산과 점검에서만 뺀다. 출근 1분 안에 퇴근하면 한 번 더 묻고, 퇴근 없이 16시간이 지나면 알린다.

## 시연용
- 급여 탭의 **지금 점검**: 월급날이 된 것처럼 에이전트를 바로 실행
- 결과 아래 **에이전트 동작 보기**: 입력, 판단, 도구 실행, 결과 순서 확인
- `POST /api/dev/daily-check`: 매일 도는 자동 점검을 지금 실행
- 계약서 탭 아래 **에이전트 동작 기록**: 도구 호출과 판단 과정 확인

## 계산 범위와 한계
- 임금: 기본급, 주휴수당(계약상 요일을 모두 출근한 주), 5인 이상 사업장의 야간과 1일 연장 가산. 휴일 가산, 연차수당, 퇴직금, 세금과 보험 공제는 아직 계산하지 않는다.
- 결과는 법적 판단이 아닌 참고용이다.
