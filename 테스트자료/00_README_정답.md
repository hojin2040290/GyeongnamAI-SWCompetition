# 알바지킴이 테스트하는 법과 정답지

개발자용이라 서비스에 올리지 않습니다. 인물과 가게는 모두 지어낸 것입니다.

## 0. 테스트하는 법

### 시험 데이터로 서버 켜기
서버 켜는 명령 앞에 `TEST_DATA=true`를 붙이거나 `.env`에 넣습니다 (`TEST_DATA=true .venv/bin/uvicorn app.main:app --port 8080`, Windows는 `$env:TEST_DATA="true"; .venv\Scripts\python.exe -m uvicorn app.main:app --port 8080`).
- 시험 데이터(`data/test`)가 없으면 서버가 켜지면서 만듭니다. 평소 데이터(`data/app.db`)는 건드리지 않습니다.
- 로그에 `저장 위치: 기록 …/data/test/app.db`와 `시험 데이터로 실행 중이에요`가 보이면 됩니다.
- 로그인: `test@example.com`, `test2@example.com` ~ `test5@example.com` / `test1234` (홍길동, 2009-05-20생, 만 17세). 기본은 방금 가입한 처음 이용자라 시작 화면과 체험 안내부터 나옵니다.
- 처음 상태로 되돌리기 (서버를 끄고): `.venv/bin/python -m app.demo_db --force`.
- 아래 알바 5개 사례로 정답을 확인하려면: `.venv/bin/python -m app.demo_db --scenarios --force`. 알바마다 만든 내용, 코드가 계산한 금액, 기대 결과를 출력하고, 오른쪽 위 사업장 이름을 눌러 알바 5개를 바꿔 봅니다.
- 법 기준표는 평소 DB에서 복사합니다. 출력 첫 줄이 `법 기준표: 평소 DB에서 N건 복사`가 아니면 실행가이드 3-1절을 봅니다.

### 알바 5개 사례 (`--scenarios`로 만든 계정에 들어 있는 것)
| 알바 | 시험할 경우 | 넣어 둔 기록 | 시연 때 올릴 사진 |
|---|---|---|---|
| 1. 행복편의점 도계점 | 이 폴더의 원본 시나리오 (1~6절) | 근무기록 CSV 12건(GPS), 9/27 그만둠 | 계약서, 근무표, 사장님 메시지, 9월 명세서(557,280원), 입금내역 |
| 2. 가상분식 시험점 | 적게 받음 (5인 이상, 야간, 하루 한도 초과, 결근한 주) | 8월 근무 15건 + 실수 표시 1건 | 계약서, 8월 명세서(기본급만 753,360원), 9/10 입금내역 |

| 4. 가상베이커리 시험점 | 정보 부족 (계약서 없음, 동의서 안 냄, 인원과 휴게 모름) | 9월 근무 4건 | 사장님 메시지 |

사진과 명세서의 받은 금액은 시험 데이터에 미리 올려 두지 않았습니다. `.env`에 `DEMO_MODE=true`를 넣고, 시연 때 업로드 화면에서 데모 자료를 골라 올립니다. 명세서를 올릴 때 받은 금액을 함께 넣어야 급여 비교가 위 정답처럼 나옵니다 (그 전에는 '받은 금액이 없어 비교하지 않음').
2~5번 사진은 `알바5개` 폴더에 있고, 사진 속 금액은 코드가 계산한 값입니다 (`알바5개/manifest.json`).

**데모 자료** (`DEMO_MODE=true`, 업로드 선택 목록에 30장): 알바 5곳마다 채용공고, 근로계약서, 근무표, 급여명세서, 입금 내역, 사장님 메시지. 위 표의 '시연 때 올릴 사진' 말고도 올릴 수 있습니다.
- 가상베이커리 근로계약서: 9/27에 뒤늦게 쓴 계약서 (수습, 휴게시간, 주휴일 칸이 비어 있음). 9월분 명세서와 10/10 입금 내역(247,680원, 기본급만, 주 6시간이라 주휴수당 없음)
- 가상치킨 8월분 명세서(371,520원)와 입금 내역: 명세서는 있지만 입금 내역에 가게 이름이 없음 (못 받음)
- 채용공고를 고르면 그 가게 조건으로 지원 전 확인 칸을 채웁니다 (가상카페 공고는 `예시/`)

### 무엇을 눌러 보나
1. 계약서 탭: 계약서 점검 → 항목마다 결과와 'AI 에이전트 판단'이 아래 정답과 맞는지
2. 계약서 탭: 계약서 사진 읽기 → 읽은 값이 계약서 사진과 같은지. `.env`에 `DEMO_MODE=true`를 넣으면 업로드를 누를 때 이 폴더의 사진을 바로 고를 수 있습니다 (급여 탭 명세서, 자료 탭도 같음)
3. 급여 탭: 달을 고르고 지금 점검 → 계산 금액과 판단이 아래 정답과 맞는지
4. 홈: 퇴직 정산 (1번, 5번) → 기한과 판단, '받았어요/못 받았어요' 뒤 결과
5. 자료 탭: 처음에는 비어 있음. 사진을 올린 뒤 원본 그대로 열리는지, 상담 사전 자료 만들기
6. 보호 탭 (5번): 신고 후 보호 안내 문구
