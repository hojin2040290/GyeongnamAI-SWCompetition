1프로젝트 현황

요약. 청소년 아르바이트생이 출퇴근을 누르고 계약서와 급여명세서를 올리면, AI 에이전트가 필요한 점검을 스스로 골라 법 기준과 대조합니다. 위반이 의심되면 근거 조항과 사실을 붙여 알리고, 모르는 정보는 묻고, 다시 확인할 날을 예약하며, 상담 사전 자료와 신고 후 보호까지 이어 줍니다. 숫자 계산은 코드가, 법 조항 판단과 글쓰기는 AI가 맡고, AI의 판단은 코드 검증 장치가 다시 확인합니다.

2프로젝트 개요

문제

고용노동부에 따르면 청소년·청년근로권익센터에 2026년 6월까지 접수된 상담은 26만 건이 넘고, 상담의 60% 이상이 20대 초반 이하의 청소년과 청년입니다 (참가신청서 인용). 청소년은 최저임금, 주휴수당, 휴게시간, 야간근로 제한, 퇴직 후 14일 안 지급 같은 기본 권리를 잘 모릅니다. 어떤 기록과 증거를 모아야 하는지 몰라 미리 남기지 못하니, 문제가 생겨도 임금을 증명하기 어렵고, 신고 뒤 보복이 두려워 권리를 포기하기도 합니다.

대상 사용자

만 15~18세 청소년 아르바이트생(주 사용자), 보호자, 상담을 맡는 청소년근로권익센터·고용노동부 등 상담 기관.

8일 목표와 핵심기능

사용자가 기록만 남기면 에이전트가 점검을 골라 실행하고, 근거와 함께 결과를 알리며, 필요하면 묻고 예약해 다시 확인하는 흐름을 처음부터 끝까지 동작시킵니다.

#핵심기능코드가 하는 일AI가 하는 일
1근무 기록과 증거 보존출퇴근은 서버가 받은 시각으로, 올린 자료는 원본 그대로 SHA-256과 함께 저장. 위치는 동의한 경우만퇴근하면 그날과 그 주의 근무 점검
2계약서·근무 점검근무일별 만 나이로 적용 조항을 가리고 법 기준표와 대조계약서·채용공고 사진 읽기, 조항마다 정상·확인 필요·위반 의심 판단
3급여 비교와 퇴직 정산기본급, 주휴수당, 가산수당 계산과 받은 금액 비교, 퇴직 후 지급 기한 계산명세서 사진 읽기, 체불 의심 판단
4AI 에이전트 종합 점검사업장의 모든 기록을 한 줄씩 정리, 매일 9시 자동 실행종합 판단, 조언, 질문, 후속 확인 예약
5상담 자료와 신고 후 보호기록·계산·증거 목록을 문서로, 공개 게시물 주소와 화면 보존AI 요약, 보복 금지 안내 문구, 보복성 게시물 판별

3개발 세부 내용

Agent Architecture

AI는 점검마다 목표와 쓸 수 있는 도구 목록만 받습니다. 어떤 도구를 쓸지 AI가 고르면(vLLM tool calling) 코드가 실행해 결과를 돌려주고, AI는 결과를 보고 다음 행동을 정합니다. 알림, 질문, 확인 예약 같은 행동도 AI가 도구로 고릅니다. LangChain 같은 에이전트 프레임워크 없이 직접 만들었습니다.

그림 1. 알바지킴이 에이전트 구조. Memory는 실행을 시작할 때 목표와 함께 AI에게 보내고, 실행 중에는 AI가 메모·질문·예약 도구로 저장합니다. 판단 반복은 최대 30회입니다.

Workflow 예: 그만둔 사업장의 퇴직 정산 점검

  1. 입력 사용자가 그만둔 날을 저장하면 에이전트가 시작합니다.
  2. 계획 AI가 make_plan으로 "기본 정보 → 지급 기한 → 조문 → 판단" 순서를 세웁니다.
  3. 도구 AI가 settlement를 고르면 코드가 그만둔 날로부터 14일 기한과 받음 여부를 계산해 돌려주고, get_article로 법 기준표의 근로기준법 제36조를 확인합니다. 기한이 지났는데 받았는지 기록이 없으면 AI가 notify로 '남은 임금 받았어요/아직 못 받았어요'를 눌러 달라고 알리고, 필요하면 schedule_followup으로 다시 확인할 날을 예약합니다.
  4. 판단과 검증 AI가 결과·이유·근거 조항·근거 사실을 냅니다. 코드 계산과 어긋나거나 근거가 없으면 검증 장치가 돌려보내 다시 판단하게 합니다 (최대 2회).
  5. 결과 표시 검증을 통과한 판단만 코드가 저장해 홈의 퇴직 정산 칸에 보여 줍니다. 예약한 날이 되면 Memory를 받아 그 점검을 다시 시작합니다.

4구현 결과와 테스트

핵심기능 5개가 모두 동작하고, 출근부터 상담 사전 자료까지 하나의 흐름으로 이어집니다.

  • 홈: 출퇴근, AI 에이전트 종합 점검(한 줄 결론, 판단, 조언), 에이전트의 질문, 진행 상황, 알림.
  • 판단 표시: 항목마다 코드가 정리한 사실과 'AI 에이전트 판단'(결과, 이유, 근거 조항, 근거 사실)을 나눠 보여 줍니다. '에이전트 동작 보기'는 계획, 고른 도구, 도구 결과, 검증 장치의 돌려보냄을 단계별로 남깁니다.
  • 상담 사전 자료: 기록, 계산, AI 판단, 증거 목록(SHA-256, 한국 시간), 상담 기관을 한 문서로 만듭니다.
  • 모델이 없어도 동작: 기록·계산·대조는 계속하고 판단만 'AI 응답 대기 중'으로 둡니다. 모델이 연결되면 10분마다 다시 맡깁니다.

6성과와 기대효과, 한계와 향후 계획

성과

법을 몰라도 기록만 남기면 에이전트가 점검을 골라 실행하고 근거 조항과 사실을 붙여 알려 줍니다. 정답 사례에서 위반 의심 누락 0건, 급여 계산 100% 일치를 확인했습니다.

기대효과

대상지금까지알바지킴이로
청소년체불을 늦게 알고, 무엇을 모아야 하는지 몰라 증거를 남기지 못해 증명이 어려움퇴근할 때마다 점검, 서버 시각 기록과 원본 증거가 쌓임
상담 기관상담 때 기록과 금액을 처음부터 확인기록·계산·증거 목록이 정리된 상담 사전 자료로 시작
사회보복이 두려워 신고를 포기보복 금지 안내와 게시물 보존으로 신고 뒤까지 지켜봄

한계

  • 실제 모델로 모든 흐름을 반복 검증하지 못했습니다. 자동 시험은 가짜 AI로 했습니다.
  • 임금 계산은 기본급, 주휴수당, 5인 이상 사업장의 야간·연장 가산까지입니다. 휴일 가산, 연차수당, 퇴직금, 세금과 보험 공제는 없습니다.
  • 신고 뒤 공개 게시물 자동 검색은 네이버 검색 API 연결 코드만 만들었고, API 키를 받지 못해 실제로 쓰지 못했습니다. 게시물 주소를 넣어 보존하는 기능은 동작합니다.
  • 결과는 법적 판단이 아닌 참고용입니다. 실제 청소년 사용자 검증은 설문을 준비했지만 아직 결과가 없습니다.

  1. 실제 모델로 대표 사례를 반복 측정하고, 틀린 판단을 정답 사례에 더해 검증 장치를 보완합니다.
