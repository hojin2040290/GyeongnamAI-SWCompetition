작품명알바지킴이: 청소년 중심 아르바이트 근로권익 점검 및 보호 AI Agent
해결 문제청소년 아르바이트생이 최저임금·주휴수당·휴게·야간근로 제한·퇴직 후 14일 안 지급 같은 권리를 몰라 체불을 늦게 알고, 기록과 증거가 없어 증명하기 어렵고, 신고 뒤 보복이 두려워 권리를 포기하는 문제
대상사용자만 15~18세 청소년 아르바이트생, 보호자, 청소년근로권익센터 등 상담 기관
Agent Goal출퇴근·계약서·급여 기록을 법 기준표와 대조해 조항마다 정상·확인 필요·위반 의심을 근거 조항·사실과 함께 판단하고, 알림·질문·후속 확인·상담 사전 자료·신고 후 보호까지 이어 준다
사용 AI/LLM/모델Qwen3.8-27B (GPU 서버의 vLLM 0.30.0, tool calling). 후보 9개를 같은 시험(속도, 도구 호출, 판단, 사진 읽기, 한국어)으로 비교해 선정. 도구 선택·조항 판단·사진 읽기·글쓰기를 맡고, 숫자 계산은 맡기지 않음
사용 Tool/API/Data/장비도구 32개(코드가 실행): 임금·만 나이·지급 기한 계산, 법 조문·판례, 기록·증거 조회, 알림, 질문, 확인 예약, 게시물 검색 등 · API: 법제처 국가법령정보(조문·최저임금 고시·판례를 법 기준표로), 네이버 검색(공개 게시물) · Data: SQLite(사용자 기록, 원본 파일과 SHA-256), law_params.json(법 기준값과 출처) · 장비: 휴대폰 웹, GPS(동의한 경우만)
Memory/State/Feedback 구현Memory: 실행을 시작할 때 지난 메모, 질문과 답, 예약한 확인, 진행 상황(점검 결과 요약)을 목표와 함께 AI에게 보냄. 실행 중에는 AI가 remember·ask_user·schedule_followup 도구로 저장. 지난 종합 점검 뒤로 기록이 그대로면 AI를 다시 부르지 않음 · Feedback: 검증 장치가 코드 계산과 다른 판단, 법 기준표에 없는 조항, 근거 없는 판단을 돌려보내 다시 판단(최대 2회). AI 글의 링크·한자·내부 이름·글자 수 초과도 돌려보냄. 사용자가 질문에 답하면 그 점검을 다시 시작
핵심 Workflow
(End-to-End)		입력 → 판단/계획 → Tool/API/Data → 실행 → 결과 → Feedback
  1. 사용자가 퇴근·급여 저장·그만둔 날 저장을 누르거나, 매일 9시·예약한 날이 되면 에이전트가 시작한다 (사용자마다 대기줄에서 차례로 실행).
  2. AI가 목표, 도구 목록, Memory(지난 메모·질문과 답·예약·진행 상황)를 받고 make_plan으로 할 일을 세운다.
  3. AI가 도구를 고르면 코드가 계산·조회해 결과를 돌려주고, AI는 결과를 보고 다음 도구를 고른다 (최대 30회).
  4. AI가 조항마다 결과·이유·근거 조항·근거 사실을 낸다.
  5. 검증 장치가 코드 계산·법 기준표와 대조해 문제가 있으면 돌려보내 다시 판단하게 한다.
  6. 결과를 저장하고 알림을 보내며, 모르는 정보는 묻고, 다시 확인할 날을 예약하고, 메모와 조언을 남긴다.
  7. 답을 받거나 예약한 날이 되면 메모를 읽고 그 점검을 다시 시작한다. 모든 단계는 화면의 '에이전트 동작 보기'에 남는다.
핵심기능 3~5개1) 근무 기록과 증거 보존(서버 시각, 원본+SHA-256) 2) 계약서·근무 점검(사진 읽기, 근무일별 만 나이) 3) 급여 비교와 퇴직 정산 4) AI 에이전트 종합 점검(판단·조언·질문·예약, 매일 자동) 5) 상담 사전 자료와 신고 후 보호(보복 금지 안내, 게시물 판별·보존)
기존자산 / 8일 신규개발분기존자산: 오픈소스 라이브러리(FastAPI, SQLModel, APScheduler, httpx, Playwright), vLLM, Qwen3.8-27B, 법제처·네이버 API · 8일 신규개발: 앱 전체(에이전트 반복과 도구, 검증 장치, 계산, 화면, 시험). 앱 코드 약 10,200줄, 시험 코드 약 5,100줄, 커밋 262개. 저장소는 9/27 빈 상태에서 시작
대표 테스트 5건 결과가상 사업장 5곳(검증 장치 기준): ① 수습 감액 요건 미충족·청소년 야간근로 → 위반 의심 ② 기본급만 받음 → 124,872원 적게 받음 ③ 모두 지킨 곳 → 최저임금·급여 정상 ④ 계약서·동의서 없음 → 위반 의심, 모르는 정보는 추측 없이 확인 필요 ⑤ 휴게 없음·퇴직 후 미지급(기한 9/12 지남) → 위반 의심, 신고 후 보호 · 정답 사례: 위반 누락 13건 중 0건, 정상 오탐 0건, 급여 계산 8/8 일치, pytest 213개·화면 시험 19파트 통과
